@@WORKS@@
Pipeline

一条管线，端到端可验证

从 spec 到 MP4 的每一步都留痕：契约页头注释、容器 metadata、sidecar。

01

Spec 即源码

画幅、场景、动画、时序全部声明在 JSON 里，可 diff、可版本管理、可批量生成。

02

场景与模板

7 类内置场景、7 个自定义模板，6 种入场动画与 5 种转场自由组合。

03

旁白驱动时长

TTS 生成语音后反推场景时长，字幕、BGM、SFX 在同一时间轴上对齐。

04

多轨时间轴

场景 / 旁白 / 音效 / 背景音乐四轨独立编排，混音与转场按帧确定性求解。

05

Studio 帧级预览

等比缩放画布、逐帧步进、安全区与网格、播放头联动场景与属性面板。

06

来源验源

spec sha256 → HTML 头注释 → MP4 comment / sidecar，三重锚点可回溯。

07

确定性导出

CEF 离屏渲染 + GL 合成 + FFmpeg 编码，同 spec 两次输出逐字节一致。

08

C++ 媒体基座

播放、解码、硬解、转码与 GL 渲染复用同一套 xmedia-kit 内核。
